# Источники данных и происхождение документов

## 1. Принципы сбора

1. Используются **только официальные открытые источники**.
2. Никакие технические ограничения не обходятся: не решаются CAPTCHA, не
   обходятся авторизация и paywall. `robots.txt` каждого хоста проверяется
   перед запросом (`ingestion/http_client.PoliteHttpClient.allowed`).
3. Если файл недоступен автоматически (403/401, запрет в `robots.txt`,
   редирект на защищённый CDN), он **не скачивается**, а регистрируется со
   статусом `download_status = manual_required` вместе с URL.
4. Оригинальные файлы никогда не изменяются. Нормализация применяется только к
   извлечённому тексту.
5. Соблюдаются: реальный User-Agent, тайм-ауты, повторы с экспоненциальной
   задержкой, ограничение частоты запросов (по умолчанию 1 запрос/с на хост).

## 3. Что сохраняется для каждого документа

Поля реестра (`documents` в SQLite и `data/registry/documents.csv`):

```
document_id, title, short_title, authority, document_type, document_number,
adoption_date, effective_date, expiration_date, status, version_status,
jurisdiction, language, source_url, page_url, source_authority, source_tier,
parent_document, amends_document, amended_by, version, topic, download_date,
download_status, sha256, size_bytes, content_type, local_file, n_pages,
n_chunks, notes
```

Это позволяет доказать происхождение каждого фрагмента: от текста ответа →
`chunk_id` → `document_id` → `source_url` + `sha256` + `download_date` →
локальный файл в `data/raw/`.

## 4. Языковая фильтрация

ЕЭК публикует один и тот же акт на пяти официальных языках Союза. Файлы
разных языков часто имеют похожие имена, а на `docs.eaeunion.org` русский текст
публикуется как `<stem>.pdf`, тогда как `<stem>.docx` может содержать
армянскую, казахскую, киргизскую или белорусскую версию.

Поэтому применяются два независимых фильтра:

1. **по имени файла** — на этапе обнаружения (`metadata.file_looks_russian`);
2. **по содержимому** — после парсинга (`normalizer.is_russian_text`):
   документ должен быть кириллическим и не содержать заметной доли букв,
   которых нет в русском алфавите (ә, ғ, қ, ң, ө, ұ, ү, һ, і, ў…).

Документы, не прошедшие второй фильтр, остаются в реестре с указанием
фактического языка и **исключаются из индекса**. Всего по этой причине
исключено 126 файлов из 755.

Известное следствие: на части страниц Коллегии `<stem>_doc.pdf` — это
англоязычный перевод, а русская версия имеет другое имя файла, поэтому такие
акты в индекс не попадают. Перечень затронутых документов и способ устранения —
в [limitations.md](limitations.md), раздел 2.1.

## 5. Отсканированные документы

Значительная часть рекомендаций Экспертного комитета опубликована как
**отсканированные PDF без текстового слоя**. Для них:

* текст не извлекается и **не додумывается**;
* в индекс попадает единственный «карточный» чанк, содержащий только
  дословные метаданные из реестра (официальное название, номер, орган, URL) и
  явное предупреждение, что содержание не проиндексировано;
* документ остаётся находимым по МНН из названия, и система может указать на
  него ссылкой, не цитируя текст, который она не читала.

Чтобы проиндексировать такие документы полностью, включите OCR (см. README,
раздел «Опциональный OCR»).

## 6. Даты обращения

`download_date` записывается при каждом обращении к источнику. Он же
показывается в карточке цитаты в интерфейсе. Первичная выгрузка корпуса для
настоящей работы выполнена 10.08.2026.

## 7. Ограничения сбора

| Ограничение | Следствие |
|---|---|
| Страницы `docs.eaeunion.org` иногда отвечают 404/500 | часть актов может отсутствовать; ошибки логируются, документ не выдумывается |
| Форматы `.doc` и `.rtf` не парсятся | такие документы остаются в реестре, но не индексируются |
| Отсканированные PDF | индексируется только карточка документа |
| WHO отдаёт файлы через редиректы на CDN | помечено `manual_required` |
| Официальные консолидированные редакции публикуются не для всех актов | `version_status = requires_expert_validation` |

## 8. Юридический статус корпуса

Документы являются официально опубликованными нормативными правовыми актами и
рекомендациями органов Евразийского экономического союза. Они загружены в
учебных и исследовательских целях, хранятся локально в неизменном виде, не
перепубликуются и не распространяются. Ответы системы содержат ссылки на
первоисточники на официальных сайтах.
